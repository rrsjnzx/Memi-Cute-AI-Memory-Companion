# 人物装饰素材

本目录包含 24 张透明底人物装饰图，每站 4 张：ChatGPT、DeepSeek、Claude、Kimi、Grok、千问。

这些角色图由本项目使用生成式 AI 制作，并在本地进行裁剪、透明边界整理与尺寸压缩，用作插件界面中的非官方二创装饰。它们不是对应 AI 服务的官方角色、品牌素材或授权形象，也不表示本项目与 OpenAI、DeepSeek、Anthropic、Moonshot AI、xAI、阿里云等相关服务提供方存在合作、赞助或背书关系。

`manifest.json` 记录每张成品图的处理来源文件名、原图 SHA-256、裁剪矩形、输出尺寸、输出 SHA-256 和受力锚点；这里的 `source` 指项目生成阶段保存的原始图片文件，仅用于复现裁剪流程，不表示素材来自第三方作者。

千问 4 张使用项目生成阶段保存的两张原始图进行固定分区及按轮廓分离的多边形遮罩，避免相邻人物接触时被错误合并。其余站点同样只对项目生成的原始图做本地裁剪与整理，不在插件运行时调用生图服务。

横向姿势以胳膊、书堆或抱枕的实际支撑位置对齐框顶；垂直扒边姿势以图中的扶边线对齐对应左／右边框。PNG 只用于装饰；软团子的受力形变使用独立 SVG 节点，不拉伸人物 PNG 冒充软体。
